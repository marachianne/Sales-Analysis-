📊 Sales Data Analysis Using SQL

Welcome to my Sales Data Analysis project! 🎯
This repository contains an end-to-end SQL analysis of a sales dataset. The goal of this project is to explore sales performance, identify business insights, and segment customers using advanced SQL queries.

🔍 Project Overview

The analysis covers:

Inspecting and exploring sales data

Understanding revenue trends across product lines, years, months, and deal sizes

Identifying best-selling products and customer behavior

Performing RFM (Recency, Frequency, Monetary) analysis to classify customers into segments (loyal, active, potential churn, etc.)

📂 Dataset

The dataset sales_data1 includes information such as:

ORDER_NUMBER, ORDER_DATE, CUSTOMER_NAME

PRODUCTLINE, PRODUCTCODE, SALES, DEALSIZE, STATUS

YEAR_ID, MONTH_ID, COUNTRY, CITY, TERRITORY

🛠️ Tools Used

SQL (MySQL / SQL Server) → for querying and analysis

📈 Key Analyses & Insights
1️⃣ Sales Performance

By Product Line → Classic Cars generated the highest revenue

By Year → The best-performing year was identified

By Deal Size → Medium deal size contributed the most revenue

By Month → November 2004 was the top sales month

2️⃣ Product Insights

In November, Classic Cars were the most sold product line

The best-selling products in the USA and UK were analyzed

3️⃣ Basket Analysis

Identified products frequently sold together using order-level grouping

4️⃣ Customer Segmentation (RFM Analysis)

Customers were segmented into groups such as:

🟢 Loyal Customers (frequent, high spenders)

🟡 Active Customers (buy often, lower value)

🔴 Lost Customers (haven’t purchased in a long time)

🟠 Potential Churners

⚪ New Customers
